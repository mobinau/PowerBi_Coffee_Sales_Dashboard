# PowerBi_Coffee_Sales_Dashboard
📌 About the Project

This project is an analytical dashboard for coffee sales, built with Power BI, designed to explore sales performance, trends, and customer purchasing patterns. The main goal was to practice data visualization skills, writing Measures with DAX, and building an interactive, user-friendly dashboard.
✨ Features

    📊 Map Visualization: Displays sales distribution by geographic location to identify high-performing regions

    📈 Data Visualization: Interactive charts for analyzing sales, comparing products, and tracking trends over time

    🧮 Measures & DAX: Custom calculations using DAX functions such as total sales, average sales, order counts, and trend analysis

    🎛️ Interactive Filters: Filter data by time period, product type, and geographic region

    🖱️ Interactivity: All charts and filters are cross-connected and respond to each other

🛠️ Tools & Technologies

    Power BI Desktop – Dashboard creation and visualization

    DAX Language – Writing Measures and analytical calculations

    Data Modeling – Building relationships between tables

🎯 Project Goals

This project was built to practice and strengthen the following skills:

    Data visualization and user-friendly dashboard design

    Writing Measures and using DAX functions

    Building an interactive dashboard for business analysis
